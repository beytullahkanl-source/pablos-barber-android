# PABLO'S BARBER Android

PABLO'S BARBER randevu sistemini Android uygulaması olarak açan proje.

- Uygulama adı: **PABLO'S BARBER**
- Paket adı: `com.pablosbarber.app`
- Canlı site: `https://pablos-barber-beytullahkanl-3026.vercel.app`
- Minimum Android: Android 7.0 (API 24)

## Hazır APK

`releases/PABLOS-BARBER.apk`

## Otomatik APK Build

GitHub Actions workflow:
`.github/workflows/build-apk.yml`

Repo GitHub'a yüklendiğinde:
1. Actions sekmesine gir.
2. **Build PABLO'S BARBER APK** workflow'unu çalıştır.
3. Çıktı olarak `PABLOS-BARBER.apk` oluşur.
